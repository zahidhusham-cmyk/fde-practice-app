# Northstar Desk — Interview Tasks

You have 45 minutes. You may use your own editor and any AI assistance. We care more about how you work than how many tasks you finish.

The app is an internal support desk used by Northstar Retail's IT team. Agents already browse tickets, open a ticket, and update its status or assignee.

Work in whatever order you like. A strong session usually finishes two or three of these.

## Task 1

Users have reported that the ticket list isn't showing everything it should. Please investigate and fix the issue.

## Task 2

Agents want to find tickets more easily. Add a way to filter or search the ticket list. Changes should work end to end.

## Task 3

Agents should be able to open a new ticket from the dashboard. Follow existing patterns, validate input, and add a test.

## Task 4 (stretch)

On the ticket detail page, add a "Summarize" action that produces a short summary of the ticket. The summarizer should be swappable later (for example, for an LLM). A simple implementation is fine for now. Include a test.
